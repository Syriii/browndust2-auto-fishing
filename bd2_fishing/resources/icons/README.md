# 应用图标

- `app.ico`：用户选定 B 版图标，包含 16–256 像素共 9 档，供 Windows 窗口及 EXE 使用。
- `app-64.png`：主窗口标题区使用的小图。
- 原图保存在 `docs/design/assets/app-icon.png`，来自用户提供的 Fishing Voyage 封面参考，通过内置 imagegen 创作；保留人物与持竿动作，背景海浪后置，露出少量船舷。

更新时同步两种资源；PyInstaller 和 Python 包资源清单均包含图标。草稿、提示词和候选版本在本机 `.local/maintenance/icon-design-20260909/`。
