# 配置说明

[文档目录](../README.md) · [使用指南](usage.md)

## 位置与保存

源码运行读取 `.local/config.ini`；便携版读取 EXE 旁的 `config/config.ini`；普通 wheel 安装读取用户主目录下 `BD2_AutoFishing/config.ini`。配置不存在时，[settings.py](../../bd2_fishing/infrastructure/settings.py) 从唯一的[默认配置资源](../../bd2_fishing/resources/default.ini)生成。路径不随终端当前目录变化。本次已将原源码 config.ini 原样移入 .local，保留个人取值和注释。

点击开始时保存界面管理的选项并应用到本次任务；保存保留其他配置项及注释。已有配置中的明确取值优先于新版本默认值。手动修改后，在下一次启动任务时应用。

复选框显示 **✓ 表示开启**，空框表示关闭；灰色表示当前不能修改，仍保留勾选状态。

## 设备与时延设置

左侧 **设备与时延设置** 打开右侧设置表单，点击 **返回运行记录** 回到日志。左侧任务区始终保留；左下角同一个按钮在开始、停止、正在停止之间切换。运行期间设置只读，停止后可修改；保存后下次开始生效。
恢复默认值只修改当前表单，点击保存才写入配置；保存保留其他选项和注释。

每行按“设置项与允许范围、当前值、建议 / 参考”排列，范围放在设置名称下方，建议紧邻输入框。默认参考值不是本机最优值；
检测或校准成功后，对应输入框右侧更新为实测尺寸或本机间隔建议，不自动覆盖正在填写的值。
设置嵌入主窗口，表单可以滚动，保存区固定在底部；页面等待与逐帧诊断默认折叠。草稿切页保留，开始前需保存或撤销；退出时提示是否放弃未保存的更改。主窗口在鼠标所在显示器工作区居中。

### 窗口与分辨率

- **自动适配**：每次开始重新读取游戏客户区，按实际尺寸计算比例区域和像素阈值。无需填写桌面分辨率；`[scale]` 是识别阈值的参考尺寸，不要改成当前电脑分辨率来代替自动适配。
- **核对指定尺寸**：额外检查客户区宽高，尺寸不符就停止。用于维护固定布局；不会自动改变游戏分辨率、移动或缩放窗口。
- **检测游戏窗口**：只读显示客户区大小、位置、所在显示器边界和窗口 DPI。检测到跨屏、最小化或未找到游戏时明确提示，不发送游戏输入。宽高右侧显示实测像素，点击“采用检测尺寸”填入表单后保存。
- 同时采样后台线程请求等待 5/10/20ms 的实际中位数和最大值，帮助发现本机等待精度差异。它不包含输入守卫、截图、游戏帧率或网络响应，不能直接作为最佳 QTE 参数。

客户区不包含标题栏或边框。运行中改变窗口大小、位置或失焦仍会停止；其他分辨率的自动缩放不等于识别已全部验收。

### 时延与等待

**校准本机间隔**在未开游戏时也可执行。对 5/10/20ms 的可取消等待各测量 32 次，分四批
采集，记录中位数、p95、最大值、波动范围与异常尖峰。页面同时展示 p95 和最大值。
仅从 p95 和最大抖动均合格的档位中分别选择检测/反馈建议；反馈至少 10ms，不能因为 5ms
稳定就直接假设 10ms 稳定。没有合格档的字段保持原值；这是基础等待筛选规则，不是游戏最佳值。
点击**采用校准建议**仅更新表单，保存后下次开始生效，按住和松开后等待保持原值。
关闭窗口取消测量。校准报告位于运行根目录的 `data/calibration/latest.json`，不写入个人 INI。
报告附已保存设置和设备/系统上下文；没有游戏时设备为空并记录原因，不提供虚构的窗口尺寸。
设备信息仅作上下文，不影响基础校准结果；本次校准不会改变游戏窗口或输入设置。
它是基础节流校准，不包含截图、识别、输入驱动或游戏响应，仍不是按命中率寻找最优参数。

| 设置 | 默认值 | 影响 |
| --- | --- | --- |
| QTE 检测间隔 | 20ms | 控制循环的节流；实际周期还包含截图、识别与输入 |
| QTE 按住时间 | 100ms | 一次空格按下到松开的等待 |
| QTE 松开后等待 | 200ms | 释放空格后再继续控制的等待 |
| 反馈观察间隔 | 20ms | 独立观察线程的节流；与控制检测分开 |
| 开始前／结算／轮次间等待 | 各 4s | 对应页面转换和动画等待 |
| QTE 超时上限 | 35s | 控制达到期限后取证并停止，不是按键节流 |

界面使用毫秒展示前四项，INI 中以秒保存：`loop_sleep_seconds`、`qte_hold_seconds`、
`qte_settle_seconds`、`feedback_poll_seconds` 均属于 `[time]`。
缺少新键的旧配置保持原输入时序。默认仍调用旧输入库；显式改变按住或松开等待后，
由统一输入适配器顺序按下、等待、松开、等待，等待可取消，不改其他动作的全局暂停。
默认输入库包含约 100ms 按住及总计 200ms 松开后暂停，不能把 20ms 检测间隔当作整次输入时延。

2026-09-10 源码蓝区判定改为可靠内部区间，不再用 `[roi] qte_press_tolerance_pixels`
扩大蓝区按键范围；该值仍用于现有黄色判断等逻辑。仅调成 0 不能修复旧 EXE 的蓝色掩膜膨胀，
需要后续包含此源码修复的新构建。未自动改变用户按住、松开等待或检测间隔。

检测间隔越小通常越频繁，但不是零成本；按住过短可能漏键、后续等待过长可能错过下个目标。
建议保留默认值作为基线，每次只调整一项，比较同类场景中的实际命中、反馈未确认、停止行为与耗时。
设备检测不会声称已经测出游戏响应，也不会自动套用其他电脑的参数；当前尚无以真实命中率为目标的自动搜索调参。
每次输入的取证元数据记录 `configured_timing`，观察统计记录 `configured_poll_seconds`，便于对照不同配置。
调整结果只在本机配置保存，不改仓库默认值。

### 结算和续钓

结算识别现在使用完整的 `fish_end_wait_time`（0–30 秒），不再将大于 4 秒的设置截短。
确认面板后，关闭动作前重新核对画面；点击一次后等待移动和抛竿控件恢复，再允许继续。
已回到可确认的钓鱼待机页时可跳过关闭点击，原 unknown 结果仍保留。
轮次间等待结束后、下一次抛竿之前再检查一次待机页。

`[recovery] max_unconfirmed_rounds` 默认 2，表示连续未确认结果最多允许续钓两轮，第三轮停止；
设为 0 表示结果未确认时不续钓，允许范围 0–5。明确捕获后计数清零。
没有控件证据、页面发生变化、关闭后仍有面板或窗口保护触发时停止，不重复盲点或重抛。
此恢复仅覆盖可确认页面，不放宽 QTE 整轮超时后的停止策略，也不自动恢复特殊机制。

## 常用开关

| 配置项 | 当前默认值 | 含义 |
| --- | --- | --- |
| `[app] location` | 自动识别 | 页面启动时选中的钓场 |
| `[app] prevent_sleep` | `false` | 仅运行期间保持唤醒 |
| `[backpack] auto_clear_enabled` | `true` | 满包后自动出售；关闭则满包停止 |
| `[ocr] enabled` | `true` | OCR 总开关，影响地点及满包等文字判断 |
| `[diagnostics] qte_detail_log` | `false` | 逐帧诊断写入文件，不刷页面 |
| `[diagnostics] failure_max_events` | `100` | 各类失败证据分别保留的最大数量 |
| `[diagnostics] max_events` | `10` | 成功结算证据的最大数量 |

## 各配置段用途

| 配置段 | 配置内容 | 坐标或单位 |
| --- | --- | --- |
| `[hook]` | 等待上钩感叹号 ROI、黄色 HSV 范围 | ROI 为客户区百分比 |
| `[roi]` | QTE 总区域、倒计时与色条裁剪、颜色范围、挡板尺寸和按键容差 | 总区域为客户区百分比；子区域相对总区域；尺寸与容差为参考分辨率像素 |
| `[backpack]` | 自动清包、按钮坐标、点击间隔 | 按钮为客户区比例，间隔为秒 |
| `[time]` | 开始、结束等待，QTE 持续上限及循环节流 | 秒 |
| `[scale]` | 像素阈值缩放使用的参考窗口尺寸 | 像素 |
| `[ocr]` | OCR 开关、自动钓场选择、识别区域、自定义模型 | 区域为客户区百分比 |
| `[app]` | 页面初始钓场与电源选项 | 见常用开关 |
| `[diagnostics]` | 可选逐帧日志与必要取证的保留数量 | 数量为诊断包 |

完整键名、默认值及注释以 [default.ini](../../bd2_fishing/resources/default.ini) 为准；代码直接读取这份资源，不再重复维护缺省配置字符串。截图沿用 BGR 格式，再转换到 OpenCV HSV，不能套用 RGB 色值。

## 识别调整

先区分等待上钩与 QTE 阶段，再核对对应 ROI、客户区大小、缩放及坐标。夜间上钩黄色色相上限为 35，已有正负例回归；不要只凭另一时刻的 QTE 图或一条超时日志改阈值。

`[ocr] change_location_on_missing_time` 默认关闭，控制未识别到“时”时是否切换钓场。修改 ROI 或颜色前，先保存[同次诊断证据](diagnostics.md)，避免把遮挡、无新帧或阶段变化误认为阈值错误。

## OCR 模型

`[ocr]` 下 `det_model_path`、`cls_model_path`、`rec_model_path` 和 `rec_keys_path` 留空时使用 RapidOCR 包内置模型。源码自定义相对路径以仓库根目录解析；便携包内资源从 PyInstaller 资源目录解析。

需要打包自定义模型时，文件必须放在仓库内，详见[构建与发布](../development/releasing.md)。
