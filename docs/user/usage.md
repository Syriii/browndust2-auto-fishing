# 使用指南

[文档目录](../README.md) · [快速安装](../../README.md#快速开始)

## 启动和停止

1. 打开游戏，进入钓鱼场景，将客户区完整放在一块显示器上。
2. 运行源码入口 `main.py`，或完整解压便携包后运行 `BD2_AutoFishing.exe`。
3. 选择钓场和页面选项，点击 **开始钓鱼**。程序先聚焦游戏，再初始化截图和 OCR；聚焦失败则保持待机。
4. 点击 **停止任务** 结束。关闭页面也会停止任务并释放资源。

打开程序不会自动抛竿；仅使用页面按钮启停，不监听全局快捷键。运行期间开始按钮禁用，重复开始不会创建多个工作线程。停止后再次开始会重新读取所需状态、定位窗口并初始化截图与 OCR。

运行中游戏需保持前台。切换到其他窗口、锁屏、移动、缩放或最小化游戏窗口会停止任务；窗口放好后手动重新开始。不要同时运行多个钓鱼实例。

## 钓场与抛竿

可选烟波湖、浅岸、寒霜海峡、深渊巨口和亚特兰蒂斯。自动识别最多尝试 3 次，未匹配时隔 0.5 秒重新截图；仍失败时在页面直接选择钓场，例如第 4 个地点为深渊巨口。

识别到“当前位置无法抛竿”时，程序先沿用恢复动作：向前移动 2 秒、点击游戏画面并重新抛竿。同一轮恢复后仍失败才停止，请手动调整位置。恢复动作不受自动清包开关影响，重抛后重新计算等待上钩时间。

## 背包处理

自动清包默认开启。识别到“背包已满”后执行出售；关闭时满包停止，手动整理后重新开始。不按固定鱼数清理，扩容后仍以游戏提示为准。

满包提示依赖 OCR。关闭 `[ocr] enabled` 后，不能保证检测到满包并停止。手动的一次清包工具会明确执行出售，详见[工具说明](../development/tools.md)。

## 多显示器与电源

支持游戏完整位于任意单块显示器，包括虚拟桌面的负坐标屏幕。客户区跨屏或超出屏幕边界时需先调整位置，目前不拼接跨屏截图。屏幕热插拔、唤醒或修改显示器排列后，等待显示器稳定，再手动开始任务。

“运行时防止自动息屏 / 睡眠”默认关闭；开启后仅在任务期间请求保持唤醒，退出时释放。它不阻止主动睡眠、合盖、锁屏或屏幕保护程序。锁屏、睡眠和休眠期间不支持钓鱼，恢复后不会自动续跑。

手动关闭显示器、拔线或远程桌面断开可能影响截图。相关 Windows 实现依据见 [SetThreadExecutionState](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-setthreadexecutionstate) 和 [DXGI 错误定义](https://learn.microsoft.com/en-us/windows/win32/direct3ddxgi/dxgi-error)。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 无法识别钓场 | 查看 OCR 日志，在页面手动选择钓场 |
| 一直等待上钩 | 保留该轮超时 ZIP，核对感叹号原图、同帧掩膜与元数据，不仅凭峰值下调阈值 |
| QTE 出现 MISS、FAIL 或未确认 | 查看游戏反馈和按键归属；两者分别统计，未确认不是已证实的失败 |
| QTE 消失但没有鱼获 | 查看整条鱼结算，只有奖励证据充分时才确认捕获 |
| 修改源码后 EXE 没变化 | EXE 是独立构建产物，需重新构建并部署 |

日志与证据包的位置、字段和限制见[日志与诊断](diagnostics.md)。
