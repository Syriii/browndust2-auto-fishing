# 使用指南

[文档目录](../README.md) · [下载安装](../../README.md#快速开始) · [配置说明](configuration.md)

本页说明 0.4.4；下载包与验证结果以对应 Release 为准。首次打开图鉴会短暂保留原页面，首屏准备好后再切换。图片按可见区域加载，滚动时自动补齐；首次开始钓鱼仍需初始化识别资源。

## 开始钓鱼

1. 完整解压 Windows ZIP，运行 `BD2_AutoFishing.exe`，程序保持待机。
2. 在游戏中进入 Fishing Voyage 码头、选岛页或钓场；钓场内站到可抛竿位置，窗口完整位于一块显示器上。
3. 在“钓鱼”页选择自由钓鱼或按目标钓鱼，核对钓场、满包处理和保持唤醒选项。
4. 需要时打开左侧底部“设置”，检测窗口、校准基础等待或手动调整参数并保存。全部设备与时延参数仍在此处。
5. 点击底部“开始钓鱼”。程序聚焦游戏并初始化截图、OCR；失败时显示原因并停止。

任务运行时游戏需保持前台。失焦、锁屏、移动、缩放或最小化游戏窗口会停止；整理好窗口后手动重新开始。仅页面按钮控制启停，不监听全局快捷键，不同时运行另一个钓鱼程序。

左侧导航切换钓鱼、图鉴、目标、鱼获和设置，切换不改变窗口高度；底部启停与状态一直保留。钓鱼页上方并排显示任务设置和本次进度，下方运行日志默认显示，可筛选运行信息、警告／错误和详细诊断，也可关闭自动滚动以查看之前的记录。日志目录、异常截图和更新与存储入口位于日志框下方。运行中不能改配置或目标，关闭窗口会先请求停止并释放输入。

## 图鉴和目标

图鉴内置六岛 84 种鱼图。简体、繁体与已登记译名均可搜索；按钓场、昼夜、稀有度筛选，白天和夜晚筛选都包含全天鱼。滚轮连续浏览，右上两个图标切换网格和列表。

左侧默认显示密集小图，列数随窗口宽度调整，也可切换列表。点击任意鱼图或列表行，右侧固定详情区随之更新；切换视图不改变详情区位置。两种视图的字段一致，包括稀有度、钓场、时段和已有具体机制；不重复显示繁简译名行。原攻略中的作者个人尺寸纪录不会显示成你的成就。

设置目标的步骤：

1. 在目标页点击“添加目标”，或在图鉴点击“选择目标”，先选新选鱼的要求：任意尺寸、MAX 最大、MIN 最小或 MAX ＋ MIN。
2. 点击鱼卡多选，再点同一张取消；可在已选区域分别调整每条鱼的要求。
3. 点击“保存并使用”，在“目标”页核对。目标页添加时导航保持在目标，取消返回待办并保留原条件。该页也可改条件或移除鱼。
4. 点击“开始钓鱼”。程序优先处理当前钓场可钓的目标，再跨岛，按游戏时钟等待所需昼夜。

任意尺寸要求首次确认捕获即可；MAX／MIN 只按本次捕获的尺寸标签完成，普通尺寸不计。MAX ＋ MIN 是两项独立要求，先完成哪一项就清除哪一项。全部要求完成后停止，不自动转成自由钓鱼。待完成条件会保留到下次启动，历史鱼获不抵扣新设置的任务。

尚未确认地点或昼夜时会继续观察并显示等待状态，可随时停止。导航不购买许可证；从游戏主页进入钓鱼玩法仍需手动操作。跨岛与昼夜调度已有离线回归，完整游戏效果仍待使用反馈。

## 鱼获记录

鱼获页按“全部、首次、彩色、最大、最小”分别筛选，左侧为密集小图或列表，右侧固定显示所选记录的鱼图、资料、捕获时间、尺寸与等级；使用“加载更早记录”查看历史。首次按鱼种记录，彩色按图鉴中已确认鱼种的传说稀有度分类。图片统一使用内置图鉴；旧记录通过明确名称或已核实图标关联参考资料，不改写原始捕获确认、首次标记或目标。无法匹配时显示待补充状态，结算截图保留作核验依据。

尺寸、等级、边框颜色和个人新纪录分开保存。红色 `Maximum Size` 表示最大尺寸，黄色 `New Record` 是个人新纪录，不能互相代替；不会按攻略尺寸推算 MAX／MIN。绿色一级和蓝色二级已有成功原图验证，MIN 与彩色三级成功页仍待自然取证，未确认等级不按鱼种补填。

只有确认捕获才写入历史。鱼名暂未识别时仍保留该次鱼获及奖励截图，但不会完成指定鱼目标；同轮重复观察不会重复记录。写入失败会停止并保留结算页。目标、图片和鱼获存于 `data/fishing.sqlite3`，不随普通日志／诊断截图清理；备份数据时一并保留。

## 钓场与恢复

支持烟波湖、浅岸、寒霜海峡、深渊巨口、亚特兰蒂斯和天空岛六钓场。天空岛使用通用策略，尚待游戏验证。自由钓鱼中，已在钓场时手动选项用于策略选择，应与实际地点一致；从码头或选岛页启动则导航至所选岛屿。

待机页确认后抛竿，等待咬钩时继续等待，已有 QTE 则接续当前鱼。结算、升级提示与运行中的 150302 分层确认并关闭；QTE 结束本身不计作捕获。业务异常保留现场并持续观察、间隔尝试恢复，停止请求和窗口保护始终有效。

识别到“当前位置无法抛竿”时尝试移动、点击、重抛；仍失败则转入页面恢复，不受清包开关影响。启动前已有的 150302 提示仍需手动关闭，其他已知问题见[审查报告](../development/code-review-2026-09-14.md)。

## 背包、电源与反馈

**满包时自动清理默认开启，会出售背包物品。** 不希望出售时先取消勾选，之后检测到满包会停止。本版未实现自动锁鱼；清包仍使用固定坐标，相关确认问题保留在审查报告中。

“运行时保持唤醒”默认关闭，只在任务期间请求防止自动息屏或睡眠，不阻止主动睡眠、合盖或锁屏。显示器布局改变或睡眠恢复后，待显示稳定再重新开始；不支持跨屏拼接。

基础等待校准只测本机等待精度，不保证游戏最佳命中率。机制识别已实现不等于每种组合已完成实机验证；冰冻和绿色起按端按日常使用中自然遇到后反馈。

反馈时附版本、窗口尺寸、发生时间、日志和原始截图 ZIP，见[日志与诊断](diagnostics.md)。更新、迁移和清理见[更新说明](updating.md)。

鱼获按本地日期分组，每天从新到旧排列。可在“日期”中选择某一天，与上方成就分类一起筛选。网格小图显示尺寸、捕获时分及已确认的 MAX／MIN；右侧详情显示完整年月日和时分秒。旧记录时间损坏时归入“日期未确认”，不会计入今天。

0.4.5 起，点击图鉴或鱼获只更新选中图和右侧详情；返回页面保留当前内容和滚动位置。运行中新增鱼获仍会更新列表，不需要手动重启应用。
