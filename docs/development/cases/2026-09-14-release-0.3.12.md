# 0.3.12 图鉴滚动与文字调整

2026-09-14。根据用户反馈，移除上一页／下一页，修改文字排版和过于技术化的说明。

## 改动

- 左侧连续显示全部筛选结果，支持滚轮和滚动条；右侧整块详情独立滚动，小窗口下也能查看全部内容。
- 搜索／重置回到顶部，滚动不改变选中的鱼；小幅滚轮按区域分别累计，绑定不影响筛选框或其他窗口。
- 钓场、时段、稀有度、别名改为两列对齐；机制标题和正文统一左对齐、自然换行。
- 机制文字改为游戏现象的简短描述，如“指针碰到墙壁会折返”。程序输入规则不再作为图鉴正文，来源和支持范围放在“资料说明”。
- 本轮不改动游戏控制或目标任务，保留原有繁简搜索与机制并集。
