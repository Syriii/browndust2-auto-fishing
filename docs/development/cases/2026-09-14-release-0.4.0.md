# 0.4.0 主界面、目标与鱼获交付

2026-09-14。按已认可的第四版交互完成实现；另按用户要求回顾现存成功截图，修正 MAX 与等级记录。

## 本版行为

- 一个主窗口整合钓鱼、图鉴、目标、鱼获和设置，底部启停常驻，保留全部十项设备与时延设置及更新／日志入口。
- 六岛 84 张离线鱼图，简繁搜索与钓场／昼夜／稀有度筛选，图标切换网格和列表；列表当前行展开详情，两种视图的字段一致，无别名行和通用机制占位，切换不改变窗口高度。
- 先设任意尺寸／MAX／MIN／两者，再选鱼卡；逐鱼编辑尺寸条件，保存后使用目标模式。跨岛与昼夜等待根据实际地点和游戏时钟安排，清包与恢复后抛竿前复核条件。
- 确认捕获才记录，同轮去重；正常奖励和恢复中迟到奖励先保存后关闭。当前任务满足的要求自动移出待办，全部完成停止；旧鱼获不抵扣新任务。
- 个人 SQLite 保存原奖励截图、鱼种、厘米数、独立尺寸标签、等级与边框颜色、新纪录；全部／首次／彩色／最大／最小分开筛选，历史可持续展开。未知鱼名仍保留记录与图片，不错误完成目标。
- 目标保存失败提示并保留草稿；鱼获写入失败停止且保留结算页面，不继续点击。

## 截图与名称修复

扫描现存相关材料，读取 4239 个事件 ZIP，按原图哈希去重并人工查看 957 张结算／恢复候选图及 298 张其他大图；非事件 ZIP 内候选均为重复。完整范围、来源和缺失边界见[截图复核](../catch-markers-2026-09-14.md)。

确认 6 轮红色 Maximum Size，包括斗鱼 7.5 cm、蝴蝶鱼 30 cm、罗汉鱼 45 cm，以及三轮魔鬼鱼 600 cm。黄色 New Record 单独记录。绿色一级和蓝色二级已有成功页证据；MIN 与彩色三级成功页未找到，不能用背包图冒充结算验证。

鱼名数量连写会降低斗鱼 OCR 分数，补充双裁切鱼名确认；按真实鱼身与文字修正罗汉鱼／花羅漢、蝴蝶鱼／蝶魚（旧资料误录鰈魚）。四种客户端名称标为已核对，其余仍是参考译名。六 MAX 原图重新执行 OCR 后都能完成对应鱼种的目标。
