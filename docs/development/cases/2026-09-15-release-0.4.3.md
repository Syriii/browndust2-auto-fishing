# 0.4.3 图鉴首次白屏修复

2026-09-15；证据目录 `.local/maintenance/catalogue-first-paint-20260915/`。

## 原因与修复

旧流程先移除当前页面，再用 after_idle 创建鱼卡，首屏准备前会露出空白内容区。新流程保留旧页，将图鉴放在下层并完成几何计算、列数调整和可见图片绘制，再切到上层。遮挡中的 Tk 控件不保证收到 Expose，所以显式准备 Canvas 内容，不能只调整页面叠放顺序。

不提前解码全部 84 张图片；隐藏图鉴仍不进入常规启动渲染，滚动时按需补图。目标选鱼页共用该流程，未改变游戏输入或识别。
