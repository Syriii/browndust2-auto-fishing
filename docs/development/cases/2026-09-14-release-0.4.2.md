# 0.4.2 启动与加载验收

2026-09-14。证据目录：`.local/maintenance/startup-performance-20260914/`。

## 修复及范围

ttk 将九宫格中心平铺，旧版 5×5 中心在大面板中触发大量绘制。本版扩大到 128×128，元素宽高设置为 0，保持控件布局。仅将背景改为不透明不足以解决此问题。[Tk 官方说明](https://www.tcl-lang.org/man/tcl8.6/TkCmd/ttk_image.htm)。

桌面不再提前导入 session 和 OpenCV／OCR；第一次实际任务仍在工作线程初始化识别资源。图鉴按可见区域解码图片，页面状态不变时复用控件，鱼卡尺寸和状态相同时复用绘制。Canvas 滚动坐标避免 Windows 屏外子窗口偏移导致漏画；销毁鱼卡时解除滚动事件绑定。

## 验证
