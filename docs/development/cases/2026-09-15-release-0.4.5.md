# 0.4.5 图鉴、鱼获与页面切换闪烁修复

2026-09-15；证据目录 `.local/maintenance/gallery-refresh-20260915/`。

## 修复

图鉴把 selected 和 draft 放入整页重建键，鱼获每次选择都会销毁卡片和详情；鱼获切页还在抬到最前后才绘制。这些路径会清空可见区域并重复载入。改为保留鱼卡，只重绘改变状态的卡片，右侧 FishDetails 更新已有标签和图片。鱼获按日期、分类、视图、列数、记录 revision 缓存，无变化的选择和回页不查询历史；目标无变化也不重建。

详情直接持有 PhotoImage，缓存淘汰不会移除正在显示的图片。旧 MAX／MIN 等可选字段在切换普通记录时隐藏，避免保留上条成就。其他页面在旧页下方完成布局再显示。
