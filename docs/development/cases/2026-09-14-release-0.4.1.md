# 0.4.1 桌面界面交付

2026-09-14。用户指出实际界面与第四版原型差距过大，本轮调整实际 Tk 控件与页面排版。

## 已实现

- 统一顶部品牌、图标导航、页面标题、圆角分区与青色状态；Tk 输入框命名字体和 ttk 标签字体同步。
- 图鉴和鱼获共用鱼卡，图片、名称、时段和标记分开；筛选标签保留，网格／列表不改变窗口高度，列表详情与名称对齐。
- 任务设置、进度、设备和时延分别成组；目标选鱼复用图鉴组件，保持目标导航，保存／取消返回待办。
- 卡片支持键盘确认、刷新后焦点保留和鼠标移出取消；缩略图缓存最多 384 项。圆角 ttk 底图使用不透明背景，避免 Windows 透明底图重复重绘。
