# 0.3.11 内置图鉴验收

2026-09-14，用户授权将现有参考图鉴集成到 EXE。本轮交付只读图鉴，不实施目标任务、捕获进度或自动锁鱼。

## 使用

运行固定入口 `dist/BD2_AutoFishing/BD2_AutoFishing.exe`，待机时点击左侧“鱼种图鉴”。支持六岛 84 种离线图片、简繁名称与译名搜索、钓场／昼夜／稀有度筛选、分页及点击详情。白天和夜晚筛选均包含昼夜通用鱼。原始攻略卡片只渲染上半部鱼图，不显示作者个人尺寸纪录。

当前图鉴浏览不改变钓场或任务。开始钓鱼关闭图鉴，运行时禁用图鉴入口；关闭重开、空结果和缺图有相应状态。资料以简体参考译名展示，保留来源、别名与机制并集说明。
