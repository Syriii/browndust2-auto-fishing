## 实现与实际边界

目标草稿由重复创建下拉框改为单个 Treeview，点击尺寸列或按 Return/F2 编辑，Escape 取消。进入目标模式保留网格；悬停保留图片；滚动布局合并回调并解绑销毁的容器；目标待办按鱼 ID 复用；无变化的状态不再每 80 ms 重写；已准备的页面可直接复用。

浅灰白、系统蓝、圆角和高光边缘已进入源码及 EXE。当前是磨砂质感，不是桌面背景的实时模糊，也没有实现连续过渡动画。详见[全仓审查](../code-review-2026-09-15.md)。
