发布后 main 可继续合入文档与测试修正，已发布标签和附件保持固定；合并 main 不自动产生新版本。版本规则见[分支约定](branching.md)。

## 当前能力与限制

| 范围 | 已实现 | 仍需完成 |
| --- | --- | --- |
| 桌面 | 任务与日志同屏，单一启停按钮，嵌入设备设置，更新/截图入口 | 不承诺所有 DPI、屏幕及系统组合均已验收 |
| 普通钓鱼 | 抛竿、上钩、QTE、结算与有限恢复，满包按设置处理 | 新场景与长运行中的未确认结果仍需持续复核 |
| 地点 | 现有五地点识别和策略选择、旧地图往返刷新 | 第六岛资料、稳定岛屿身份、完整导航与玩法信息读取 |
| QTE | 黄区优先、仅蓝区内部边界与连续确认、明暗指针区分、同次入区去重 | 高速/遮挡/窄区与跨电脑实际命中率 |
| 特殊机制 | 局部红紫避让、泡泡尝试、绿色状态准备、多外观时间线 | 冰冻专用识别与解除、绿色可靠起按端、多墙、隐形/特效指针及组合技能因果 |
| 维护取证 | 失败、异常、未确认与特殊外观常驻取证；后台有界写盘 | 稀疏证据不能解释所有历史 unknown，也不能证明技能解除 |
| 设置与时延 | 配置导入和校验、客户区检测、手动参数、基础等待校准 | 游戏端到端时延基线与按真实命中率自动调参 |
| 更新 | 在线正式版、本地 ZIP、逐文件校验、备份恢复与数据保留 | 无增量包、拖放、降级、静默安装或数字签名 |

绿色控制器已有状态与模拟回归，但真实起按端未确认，实际识别不自动授权长按。泡泡发送一次按键只算尝试；红紫颜色也不等于已确认技能。完整机制链尚未贯通，详见[审计](mechanism-chain-audit.md)。

## 已验证范围

| 检查 | 结果与边界 |
| --- | --- |
| 本机离线回归 | 发布前 346 项通过，含真实截图规则回归与模拟设备/资源测试 |
| 规范和界面 | Ruff、170 文件格式及 92 模块架构检查通过；隐藏 Tk 主窗口与更新窗口检查通过，不等于可视布局全覆盖 |
| 本机候选更新助手 | 隔离目录中验证等待退出、替换、旧依赖清理、配置保留、重启及中断恢复，未操作游戏 |
| 官方附件 | 使用程序下载与解包模块完成公开 ZIP 下载、整体 SHA-256 与全清单校验 |
| 正式版查询 | 初次匿名查询遇到 HTTP 403 限流；解除后复核 0.1.0 可发现 0.2.0，0.2.0 返回无更新 |
| 发布后回归稳定性 | 修正 Windows 路径别名及轮转测试的同时间戳样本假设；最终发布/文档 PR 的 Windows CI 通过 |

本机验证证据位于 `.local/maintenance/portable-update-20260910/` 和 `.local/maintenance/publish-20260910/`，不随 GitHub 源码提供。发布阶段没有新增游戏测试；历史普通钓鱼成功不能替代新版所有机制和设备组合的实机验收。

## 下一步

1. 以明确版本与哈希开展限时游戏验收，记录配置、客户区、DPI、输入及反馈，不同时调整多个时序参数。
2. 优先复核仅蓝区、泡泡/绿色、遮挡与多指针等已有样本；新机制补全正例、负例和连续前后文。
3. 对新 unknown 先区分采集异常、文字漏检与输入归属歧义，保留原始结果，不用异常包数量推算命中率。
4. 根据实际游戏画面补岛屿资料、导航和信息读取，继续按功能边界扩展，不预建空框架。

每项完成判据见[验证计划](validation-plan.md)。
