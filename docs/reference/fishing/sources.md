## 已处理或保留的差异

| 项目 | 来源情况 | 项目处理 |
| --- | --- | --- |
| 布拉德泡泡 | 巴哈鱼表列泡泡，GameKee 该鱼条目未列 | 按用户 2026-09-14 要求纳入并集：反弹壁、分身、泡泡、黄区消失；“未列”不记成明确否定 |
| 紫色毒海浪／反甲 | 巴哈主楼旧说明可点掉；已记录的第 77 楼补充及 GameKee 提示点击扣时 | 统一视为待应对的紫色障碍，当前局部避让；不以主动试按验证。扣时数值和消除条件待实机 |
| 咬人 | 时限、扣时量及能否主动点掉存在差异 | 保留红色局部避让，记录牙齿倒数与整轮倒数；不将红色识别成冰冻，不固定硬编码扣 1 秒或 2 秒 |
| 黄区消失 | 来源对恢复条件的叙述不同 | 只依当前可见黄／蓝目标处理，连续确认后蓝区回退；不据攻略固定等待时长 |
| 弗罗斯特初始距离 | GameKee 表格 1740，旧段落曾写 1720；巴哈 1740 | 参考值取表格 1740，保留差异；距离不用于单独确认鱼种 |
| 大头鳕时段 | 本次巴哈昼表列出，夜表缺失 | 暂列白天；夜间是否出现待核对，不能从旧摘要推断昼夜都有 |
| 旧最高等级、物品锁定 | 巴哈同时存在旧 30 级文字及 31–35 表；GameKee 新更新说有锁定，旧段仍说不能锁 | 明确区分段落时间；鱼锁作为后续功能，不用旧文断言游戏没有锁定能力 |
| 龙晴金鱼、条石雕、绵云鲫鱼、巨骨蛇鱼 | 表格字样与原图名称不同 | 原图可核对为龙睛金鱼、条石鲷、棉云鲫鱼、巨骨舌鱼，旧表写法保留来源别名 |
| 天空“脆”鱼 | 巴哈表格写天空脆魚，原图字形不一致 | 保留原始表格参考名及待核对注释，不猜用户简体客户端名称 |
| 星级与尺寸 | 原图用绿色一贝壳、蓝色二贝壳、彩色三贝壳表示稀有度，另有尺寸区间与 Max/Min 印记 | 记录稀有度等级 1/2/3；本次鱼获尺寸及最大／最小状态分开。不是同鱼随机升星 |

资料图中的“最小纪录／最大纪录”是作者个人历史，不能导入用户进度。JSON 中的 `size_reference` 只摘取“尺寸”范围，当前仍标 `ocr_unverified`，不作为自动判定最大／最小鱼获的权威阈值。

昼夜参考采用各岛昼／夜鱼表。巴哈称每小时前半为白天、后半为夜间，回复提醒背景可能滞后；未来调度应以游戏时钟图标确认时段，本机时间仅用于估算下一观察时刻，不能仅凭背景或系统时间判定可钓。
